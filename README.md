# community-hierarchy

### Models of community and hierarchical structure in directed networks and of the interaction between them

##### Maximilian Jerdee, Elizabeth Bruch, Mark Newman

We implement models which model the interaction between community and hierarchy structure in directed networks. We particularly focus on models with applications to social settings, including the networks of friendship nominations found in the AddHealth data set. 

Examples of data may be found in the `\data` directory in `.gml` file formats. If a community structure is given (as a "community" attribute), it can either be taken as the fixed community structure or as the initial partition for Monte Carlo sampling over the space of possible community structure partitions.
